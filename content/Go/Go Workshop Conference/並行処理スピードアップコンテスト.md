- `sync.WaitGroup`を使用して`gorutine`の終了を待つ
  - Go 1.25からは`WaitGroup.Go`を使うのが便利
    - https://pkg.go.dev/sync#WaitGroup.Go
    - `WaitGroup.Add`と`WaitGroup.Done`の書き忘れを防ぐ
    - `go func()`の記述も不要で可読性も上がる
```go
var wg sync.WaitGroup

// AddとDone
wg.Add(1)
go func() {
    defer wg.Done()
    processFile(f)
}()

// Go
wg.Go(func() {
    processFile(f)
})
```
